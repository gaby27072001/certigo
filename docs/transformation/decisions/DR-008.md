# DR-008 — Analytics produit et politique de consentement

- **Identifiant :** `DR-008`
- **Date de décision :** `2026-10-22`
- **Statut :** `APPROVED`
- **Décision du propriétaire :** `Approuver : pipeline interne CertiGo sans SDK tiers + consentement explicite (Recommended)` (Option A)

## Contexte & Résumé
- Le pipeline d'analytics produit utilisera exclusivement `AnalyticsClient` (`CertigoDomain` / `CertigoData`) vers le conteneur Cosmos DB `events` du backend CertiGo existant, avec mise en file locale hors ligne et zéro SDK tiers ou publicitaire (`NSPrivacyTracking = false`).
- Aucune donnée personnelle n'est incluse dans les événements, et le consentement explicite UE est géré dans les réglages de confidentialité (`S-78`).
