## 1. Synthèse exécutive et vérification de l'hypothèse H11 (**VÉRIFIÉ**)

L'hypothèse **H11** du protocole de Phase 0 est **CONFIRMÉE (VÉRIFIÉE)** :
1. **Aucune icône officielle d'éditeur issue d'un kit autorisé** (Azure V24, Power Platform, Dynamics 365, Microsoft Fabric, Microsoft Entra, Primer Octicons, AWS Architecture Icons, Google Cloud, Kubernetes) n'est aujourd'hui présente ni référencée de manière tracée dans le dépôt.
2. **Côté client iOS natif (`apps/apple/CertigoNative`)**, l'application dessine **procéduralement en `Canvas` / `Path`** des **imitations de logos d'entreprise et de produits** (`NativeMicrosoftVendorBadge` reproduisant les 4 carrés rouge/vert/bleu/jaune du logo Microsoft ; `NativeEcosystemEmblem` dessinant des imitations d'Azure, Microsoft Fabric, Microsoft Security, du chat GitHub, de la flèche souriante AWS et du « G » multicolore Google) et les encapsule dans un **blason de certification** (`NativeCertificationCrest`) qui juxtapose le logo Microsoft à 4 carrés, le mot `"Certigo"` et le code d'examen (`AZ-900`, `AI-900`…). Ces visuels enfreignent directement les règles **MUST NOT** des §22A.1, §22A.2 (Niveau 3 — interdit) et §22A.6.
3. **Côté héritage Flutter (`packages/prism_ui` et `apps/mobile`)**, trois familles d'actifs violent le §22A :
   - `VendorLogo` (`packages/prism_ui/lib/src/components/vendor_brand.dart:70-258`) : 5 imitations dessinées à la main en `CustomPaint` des logos Microsoft, GitHub, Google, AWS et OpenAI ;
   - `FontAwesomeBrands-400.ttf` + `PrismBrandIcons` (`packages/prism_ui/lib/src/tokens/prism_brand_icons.dart:7-20`) : police d'icônes agrégateur (explicitement interdite au §22A.3) exposant 11 glyphes monochromes (Microsoft, AWS, Google, GitHub, Docker, Python, Linux, Apple, Android, Java, Node.js) ;
   - `AuroraMascot` (`packages/prism_ui/lib/src/components/aurora_mascot.dart:13-253` et `apps/mobile/assets/mascots/README.md`) : 7 mascottes définies explicitement comme *« chacune = une icône Azure cutifiée »* (`nimbus`, `volt`, `cosmo`, `sentinel`, `bicky`, `pixel`, `pip`).
