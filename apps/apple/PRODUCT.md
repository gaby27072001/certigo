# Certigo Apple

<!-- impeccable:product-schema 1 -->

## Platform

ios

## Users

People preparing a professional cloud certification on iPhone or iPad.
The owner approved the first complete journey: choose an objective, answer
questions, understand the correction, and resume progress.

## Product Purpose

Make focused certification practice understandable and easy to resume.
Preparation is not a promise of exam success.

## Capabilities and Constraints

- The canonical public content is a question bank, not a guided-course corpus.
- The server alone confirms correction, progression, readiness, and rewards.
- A queued answer must remain pending until a server result arrives.
- The first visual slice is a clearly labeled synthetic demonstration, separate
  from the existing development API connector and any production authentication.
- No locally calculated result may be represented as a real server verdict.
- Minimum deployment target is iOS 17. System Liquid Glass requires iOS 26
  and an appropriate Apple SDK; older systems keep native controls.
- Account/provider integration and public-bank production wiring are separate
  workstreams, not capabilities of this demonstration.
- The owner selected four English destinations: Learn, Coach, Social, Profile.
  Learn contains My Learning / Explore; Profile owns history and settings.
  Coach and Social are explicitly unavailable navigation previews until their
  services, privacy and safety contracts are implemented.
- Interface copy is English. Learning resources retain their actual language;
  the synthetic examples in this slice are French and labeled accordingly.

## Brand Commitments

Certigo retains Prism's violet signature and spectrum organized by certification.
The owner requested a beautiful native Apple experience with Liquid Glass.
Glass belongs to navigation and controls, not behind question text.
System typography and native affordances take precedence over copying Flutter
rendering effects or importing a web UI language.

## Evidence on Hand

Root DESIGN.md and packages/prism_ui/lib/src/tokens/prism_colors.dart document
the incumbent identity. CertigoNative/Sources/CertigoNativeApp.swift contains
the development-only API connector. CertigoKit test fixtures include public
MCQ examples; they do not contain a production correction service.

## Product Principles

- One clear next action, not a dashboard of competing metrics.
- Understand the explanation before chasing a score.
- Distinguish selected, submitted, pending, and confirmed.
- Never turn demo data into apparent personal progress.

## Accessibility & Inclusion

Native navigation, Dynamic Type, SF Symbols, 44-point touch targets, semantic
dark/light surfaces, Reduce Motion, and Reduce Transparency. iPad layouts
must preserve comfortable reading width and usable compact multitasking.

## Open Decisions

Exact release scope, real-account UX, and production question-bank integration
remain outside this first visual slice. The earlier objective-first composition
now lives under Learn; the former follow-up moves to Profile. The four-tab
navigation is confirmed, but the decision-workshop art-direction extension
remains a reviewable proposal, not a release approval.
